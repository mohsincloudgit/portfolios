# Muhammad Mohsin — Portfolio Website

> **Front End Developer | GHL Automation Expert | CMS Specialist**

Official personal portfolio website featuring interactive 3D WebGL scenes, smooth physics-based scrolling, dynamic animations, and responsive design.

---

## 🚀 Live Demo & Repository
- **Repository**: [https://github.com/mohsincloudgit/portfolios](https://github.com/mohsincloudgit/portfolios)

---

## ✨ Features

- **Interactive 3D Avatar & WebGL Background**: Built with Three.js for immersive visuals and mouse-responsive interactions.
- **Fluid Animation & Smooth Scroll**: Powered by GSAP, ScrollTrigger, and Lenis smooth scrolling.
- **Custom Design System**: Bespoke typography with Syne, Plus Jakarta Sans, and JetBrains Mono fonts.
- **Mobile Responsive**: Adaptive layout for all screen sizes and mobile devices.
- **Modern Micro-interactions**: Custom magnetic cursor, hover effects, interactive project showcases, and dynamic calculators.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS**
- **Bootstrap 5.3** (Grid & Layout utilities)
- **JavaScript (ES6+)**
- **Three.js** (WebGL 3D rendering)
- **GSAP & ScrollTrigger** (Motion animations)
- **Lenis** (Smooth scroll engine)

## 📁 Project Structure

```text
├── index.html              # Main HTML entry point
├── assets/
│   ├── avatar_360/         # 360-degree avatar sequence
│   ├── avatar_hires/       # High-resolution character poses
│   ├── docs/               # Resume / documents
│   └── images/             # Profile & showcase imagery
├── css/
│   └── main.css            # Core stylesheets and design system
└── js/
    ├── animations.js       # GSAP & ScrollTrigger animations
    ├── avatar-image.js     # Avatar rendering logic
    ├── calculator.js       # Interactive rate/quote calculator
    ├── data.js             # Projects, testimonials & portfolio data
    ├── hero-zone-bot.js    # Hero interaction logic
    ├── sticky-avatar.js    # Sticky character controls
    ├── three-scene.js      # Three.js 3D WebGL canvas
    └── tilt-engine.js      # Parallax & tilt effects
```

## 💻 Local Development

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/mohsincloudgit/portfolios.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolios
   ```
3. Open `index.html` in your web browser (or use VS Code Live Server / any local HTTP server).
